🧮 MBTI算法对比分析

📚 官方标准算法

标准方法：
E_score = Σ(正向E题分数) + Σ(反向I题(6-分数))
I_score = Σ(正向I题分数) + Σ(反向E题(6-分数))

实际效果：
- 正向E题5分 = +5 E倾向
- 反向I题1分 = +5 E倾向 (6-1=5)

🔧 当前实现算法

我们的方法：
if (question.reverse) {
  scores.I += (6 - score);
} else {
  scores.E += score;
}

实际效果：
- 正向E题5分 = +5 E倾向
- 反向I题1分 = +5 E倾向
