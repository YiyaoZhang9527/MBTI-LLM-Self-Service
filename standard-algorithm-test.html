已将算法重构为标准版MBTI计算方法，移除了不必要的归一化处理

❌ 原算法（复杂）

复杂归一化处理：
const normalizedScore = question.reverse ? 6 - score : score;

重复计算问题：
scores.E += normalizedScore;
scores.I += 6 - normalizedScore;

问题：
- 每道题同时给两个维度加分
- 逻辑复杂，容易出错

✅ 新算法（标准）

直接累加方法：
if (question.reverse) {
  scores.I += score; // I题直接加到I
} else {
  scores.E += score; // E题直接加到E
}

优势：
- 逻辑清晰，符合直觉
- 易于理解和维护
- 符合标准MBTI原理

📊 算法逻辑示例

示例：EI维度测试
题目分布：23道题（12道E题 + 11道I题）

场景：纯E倾向
E题（正向）：选5分 × 12题 = 60分
I题（反向）：选1分 × 11题 = 11分

结果：
E=60, I=11 → E倾向明显
MBTI类型：E___
标准算法计算过程：
1. 遍历所有题目
2. 根据题目方向累加分数
3. 比较两个方向的得分
4. 得分高的一侧确定偏好
5. 计算百分比分布
